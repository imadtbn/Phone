# Phone — متجر هواتف عربي

واجهة ثابتة RTL ومتجاوبة، مع بحث وتصنيفات وفلاتر للسعر والسعة، روابط مباشرة لتفاصيل الهواتف، سلة محفوظة محليًا وطلب عبر واتساب.

- جهة التواصل: `+213697743721`.
- الأيقونة: `src/img/icon.png`، مستخدمة في الهيدر والفوتر وأيقونة المتصفح.
- تعديل المنتجات: مصفوفة `PRODUCTS` في `src/js/app.js`.
- التشغيل: افتح `index.html` أو شغّل `python3 -m http.server 8000`.
- GitHub Pages: انشر من الفرع `main` والمجلد `/`، إذا لم يكن النشر مفعّلًا.

## قبل البيع الفعلي
الهواتف والسعات والأسعار في هذه النسخة أمثلة، ورسومات الهواتف توضيحية وليست صور المنتجات. استبدلها بالمخزون والأسعار والصور المؤكدة. لا توجد وعود بتوفر أو ضمان أو توصيل؛ يتم الاتفاق عليها مع المتجر عبر واتساب. فتح رابط واتساب يجهّز الرسالة فقط، ولا يرسلها تلقائيًا ولا يؤكد طلب شراء. لا يُحصّل الموقع دفعات ولا يرسل بيانات إلى خادم خاص. السلة تُحفظ في متصفح الزائر فقط، والملاحظات لا تُحفظ.
